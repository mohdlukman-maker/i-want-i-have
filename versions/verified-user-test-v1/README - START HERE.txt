I WANT, I HAVE — START HERE
================================

OPEN THE PROTOTYPE
------------------
1. Open the "app" folder.
2. Double-click "index.html".
3. Use Microsoft Edge or Google Chrome if Windows asks which browser to use.

The page is designed to work by direct double-click. Its React runtime is stored locally
inside app\vendor, so an internet connection is not required for the prototype to start.
If an older version appears, press Ctrl+Shift+R once.

WHAT TO TEST
------------
On a computer, use the two buttons in the notes panel on the right:
  1. Buyer: Want -> match -> chat
  2. Provider: shelf scan -> publish

On a phone-size browser, use Get started and choose I Want or I Have.
Add ?mobile=1 to the file address only when forcing the phone layout on a desktop browser.

IMPORTANT
---------
This is an interactive USER-TEST PROTOTYPE.
- AI analysis is simulated.
- Matching and provider responses are simulated.
- Chat is simulated and exists only until refresh.
- No account is created.
- No data is saved or sent to a marketplace backend.
- BGC, Taguig and Philippine-peso values are sample scenario data.

Refreshing the page resets the demonstration.
Disabled controls are intentionally outside this test version.
Do not enter real personal, payment, or confidential information.
